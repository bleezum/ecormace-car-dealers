# EcoRmacE Car Dealers

A modern, multi-page static website for a premium car dealership experience.

## Live Demo

- GitHub Pages: https://bleezum.github.io/ecormace-car-dealers/
- GitHub Repository: https://github.com/bleezum/ecormace-car-dealers

## Features

- Modern landing page with animated hero carousel
- Inventory, details, about, and contact pages
- Premium card-based layout with glassmorphism styling
- Smooth scroll reveal animations

## Run locally

Open the project folder in a browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

Then visit http://127.0.0.1:8000/
